## 🎯 ما تفعله

```
المدخل:  2002_ant

┌──────────────────────────────────────────────┐
```

خطوتان فقط: **تحقّق** ← **انسح/انشر**.

> **ملاحظة تصميمية:** أُزيل «تخصيص الزر» و«النص التلقائي» عمداً. الأول لا يظهر إلا عبر
> بطاقات X الإعلانية، والثاني غير مضمون على كل المنصات — فالأفضل حذف ما لا يعمل.

## ✅ الطريقة الصحيحة (موثّقة رسمياً من X)

| الحقيقة | المصدر |
|---|---|
| الرابط الرسمي: `x.com/messages/compose?recipient_id=…` | توثيق X — Message Button |
| معامل `recipient_id` **إلزامي** = الرقم التعريفي (لا اسم المستخدم) | توثيق X — Message Button |
| معامل `text` **اختياري** = رسالة تُملأ تلقائياً في صندوق المراسلة (يجب ترميزه) | توثيق X — Message Button |
| **الرابط يجب أن يكون في آخر سطر** لكي يرسم X الزر في أسفل التغريدة | توثيق X — Deeplinking to a Welcome Message |
| نص الزر داخل **بطاقة الرسائل المباشرة** قابل للتخصيص بحد ٢٤ خانة | بطاقة إعلانية للشركات — ليست للتغريدات العادية |
| الرابط القديم `twitter.com` يعمل بالتحويل، لكن `x.com` هو المستقبلي | مصادر متعددة ٢٠٢٦ |

### ⚠️ الحقيقة المهمة
**الزر الذي يرسمه X** («Send a private message») **نصه ثابت** ولا يمكن تغييره في التغريدات العادية — التخصيص الكامل لنص الزر متاح فقط في **بطاقات الرسائل المباشرة الإعلانية** (حتى ٤ أزرار، ٢٤ خانة لكل نص).

**لكن** ما تملكه فعلاً ويظهر للناس هو:
1. ✅ **الإيموجي** الذي تضعه قبل النص
2. ✅ **نص النداء** الذي تكتبه («راسلني على الخاص» / «استفسارات؟» …)
3. ✅ **الرسالة الجاهزة** التي تفتح داخل صندوق المراسلة عبر `&text=`
4. ✅ **شرط أساسي:** تفعيل «السماح بطلبات الرسائل من الجميع»

## 🔍 تحسين محركات البحث (SEO)

الصفحة مهيأة بالكامل للفهرسة:

| العنصر | الحالة |
|---|---|
| عنوان + وصف + كلمات مفتاحية | ✔ |
| رابط قانوني `canonical` + `hreflang` | ✔ |
| Open Graph (og:title/description/image/url/locale) | ✔ |
| X Card `summary_large_image` | ✔ |
| صورة مشاركة `assets/og-image.png` (1200×630) | ✔ |
| بيانات منظّمة JSON-LD (WebApplication + Organization + WebSite + BreadcrumbList) | ✔ |
| `robots.txt` + `sitemap.xml` | ✔ |
| الروابط الاجتماعية **ثابتة في HTML** (مرئية للزواحف) | ✔ |
| المحتوى يعمل بدون JavaScript | ✔ |
| استجابة الزواحف (Googlebot/Bingbot/YandexBot) | ✔ 200 |

### تسريع الفهرسة

- **IndexNow** مُعدّ بالفعل: المفتاح مستضاف على الموقع، وتم إبلاغ
  Bing و Yandex و Seznam و Naver (استجابة `202 Accepted`).
- **Google**: يكتشف الخريطة تلقائياً عبر `robots.txt`. لتسريعها يدوياً:
  افتح [Search Console](https://search.google.com/search-console) ← أضف النطاق ←
  أرسل `sitemap.xml` ← استخدم «فحص عنوان URL» ← «طلب الفهرسة».

> ⏳ الفهرسة في Google تستغرق من أيام إلى أسابيع، بخلاف IndexNow الذي يعمل خلال ساعات.

## 🛡️ متانة المحلِّل (مهم للمطوّر)

X يغيّر بنية HTML صفحاته دون إشعار. في أكتوبر ٢٠٢٦ أضاف حقلاً (`schema:null`) بين
`restId` و `screenName`، وهو ما كسر كل الأدوات التي تعتمد على نمط ثابت.

المحلِّل هنا يستخدم **سلسلة بدائل** لكل حقل:

```python
d["id"] = _first_group(html, [
    r'restId:"(\d+)"',
    r'rest_id:"(\d+)"',
    r'"id_str":"(\d+)"',
    r'profile_banners/(\d+)/\d+',
])
```

ويعمل على البنية الجديدة والقديمة معاً (مُختبَر على الاثنتين).
كما توجد **تدهور رشيق**: زر «أدخل الرقم التعريفي يدوياً» ظاهر دائماً، فيعمل الموقع
حتى لو حجب X عنوان IP الخادم.
