## 🎯 ما تفعله

```
المدخل:  2002_ant  +  📩  +  "استفسارات؟ راسلني"  +  "السلام عليكم…"

المخرج:
┌──────────────────────────────────────────────┐
│ 📩 استفسارات؟ راسلني 👇                       │
│ https://x.com/messages/compose?recipient_id=… │
└──────────────────────────────────────────────┘
```

## ✅ الطريقة الصحيحة (موثّقة رسمياً من X)

| الحقيقة | المصدر |
|---|---|
| الرابط الرسمي: `x.com/messages/compose?recipient_id=…` | توثيق X — Message Button |
| معامل `recipient_id` **إلزامي** = الرقم التعريفي (لا اسم المستخدم) | توثيق X — Message Button |
| معامل `text` **اختياري** = رسالة تُملأ تلقائياً في صندوق المراسلة (يجب ترميزه) | توثيق X — Message Button |
| **الرابط يجب أن يكون في آخر سطر** لكي يرسم X الزر في أسفل التغريدة | توثيق X — Deeplinking to a Welcome Message |
| نص الزر داخل **بطاقة الرسائل المباشرة** قابل للتخصيص بحد ٢٤ خانة | بطاقة إعلانية للشركات — ليست للتغريدات العادية |
| الرابط القديم `twitter.com` يعمل بالتحويل، لكن `x.com` هو المستقبلي | مصادر متعددة ٢٠٢٦ |

### ⚠️ الحقيقة المهمة
**الزر الذي يرسمه X** («Send a private message») **نصه ثابت** ولا يمكن تغييره في التغريدات العادية — التخصيص الكامل لنص الزر متاح فقط في **بطاقات الرسائل المباشرة الإعلانية** (حتى ٤ أزرار، ٢٤ خانة لكل نص).

**لكن** ما تملكه فعلاً ويظهر للناس هو:
1. ✅ **الإيموجي** الذي تضعه قبل النص
2. ✅ **نص النداء** الذي تكتبه («راسلني على الخاص» / «استفسارات؟» …)
3. ✅ **الرسالة الجاهزة** التي تفتح داخل صندوق المراسلة عبر `&text=`
4. ✅ **شرط أساسي:** تفعيل «السماح بطلبات الرسائل من الجميع»

## 🔌 API

`GET /api/lookup?u=اسم_المستخدم`

```json
{
  "ok": true,
  "id": "2068333043291402241",
  "screen_name": "2002_ANT",
  "name": "هكر اخلاقي",
  "avatar": "https://pbs.twimg.com/profile_images/...",
  "followers": 65, "following": 88, "tweets": 140,
  "protected": false, "verified": false,
  "created_at": "2026-06-20", "snowflake": "ok"
}
```

**حالات الخطأ** (ترجع `ok:false` + رسالة عربية): اسم فارغ · رموز غير صالحة · حساب غير موجود · تحديد معدل من X · صفحة محجوبة.
